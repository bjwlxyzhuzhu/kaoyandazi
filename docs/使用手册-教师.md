## 1. 教师端在哪里、怎么登录

- 教师和学生**用同一个登录框**，只是账号不同。
- 教师账号来自服务器配置（`.env` 的 `TEACHER_ACCOUNTS`，格式 `用户名:密码`）。**没有注册入口**——教师账号注册不出来，这是故意的。
- 登录后会自动进入教师端（`/teacher`），左侧导航是教师的 7 个入口；学生端入口对教师不可见，反之亦然。
- **上线前请务必改掉默认密码**（见 [第 9 节](#9-设置模型key机构评委账号)）。

> **提示**：教师端页面顶部若出现黄色条幅，说明你现在是"匿名演示模式"或"评委演示账号"状态，看板数字会与真实情况不同。演示或截图前请先确认这个状态。

## 2. 开课前：必须配置的几件事

按顺序做，做完就能让学生注册了。

| 顺序 | 做什么 | 在哪 |
|---|---|---|
| 1 | **配置模型与平台 Key** | 设置 → 模型与 Key，填入中转站地址与平台 Key，点「测试连通」 |
| 2 | **配置检索** | 设置 → 模型与 Key（检索服务）。选 `bocha` 并填 Key；**没有额度时平台会降级，不编造数据** |
| 3 | **配置邮件**（可选但推荐） | 设置 → 邮件。QQ 邮箱填 **SMTP 授权码**（不是邮箱密码）；点「发送测试邮件」验证 |
| 4 | **填机构信息** | 设置 → 机构信息（学校、学院、教师姓名），用于打印抬头与匿名替换 |
| 5 | **确认邀请码** | 设置 → 邀请码。把邀请码发给学生，他们注册时要用 |
| 6 | **检查模块分级** | 设置 → 模块分级。确认哪些模块用平台 Key（基础）、哪些要学生自带 Key（高阶），可以按班级情况调整 |
| 7 | **维护已核实资料** | 设置 → 已核实资料。把官方文件里的关键事实贴进来，检索不可用时学生也能拿到可靠信息 |

> **关于额度**：基础模块用平台 Key，学生每天有基础额度（默认 60 次）。如果担心费用，可以在 `.env` 里设月度预算（`MONTHLY_TOKEN_BUDGET`），超了会自动暂停并给出中文提示，不会静默失败。

## 3. 概览：一屏看清全班状态

「概览」是教师端首页。显示：

| 指标 | 含义 |
|---|---|
| 注册人数 | 真实学生数（**不含评委演示账号**） |
| Key 绑定率 | 有多少学生绑定了自己的 Key（决定高阶模块可用性） |
| 周活跃 | 本周有登录/操作的学生比例 |
| 今日打卡率 | 今天打卡的人数占比 |
| 7 日完成率 | 近 7 天任务的完成情况 |
| 干预触发与响应率 | 平台主动提醒了多少次、学生回应了多少次 |
| 知识库规模 | 全班录入的资料/条目总量 |
| 档案袋完成度 | 五项考核的完成情况 |

再往下是**各站完成人数漏斗**和**路径分布**（多少人选了考研/就业/考公/保研）。

**每个数字都有口径。** 鼠标停在数字上会显示这个数是怎么算出来的——**不确定口径时不要直接引用**，这是给赛事材料用的，写错口径会被追问。

**数据不足时显示"—"**，平台不做任何估算、不填占位数字。

## 4. 学生：逐个看进度、发通知、重置密码

### 学生列表

「学生」里是全班一张表，每行显示：

- 当前在第几站、选了哪条路径；
- 最近打卡与最近登录时间（**据此发现"消失"的学生**）；
- 待处理提醒（有几条干预没回应）；
- 档案缺项（哪几项没完成）。

### 学生详情

点进某个学生，可以看到：主线进度、画像与路径、方案与打卡、周复盘、院校表、成果、知识库概况、选题卡、课堂与互评、干预与选择、邮件记录、档案袋。

> **这里看不到的**（有意为之，见 [第 10 节](#10-隐私边界教师能看到什么看不到什么)）：1:1 私聊原文、会议发言原文、长期记忆内容（只显示条数）、数字分身、学生上传的文件。

### 群发通知

- 设置 → 群发通知：写标题和正文，发全班。
- 学生会在「今日」顶部看到站内通知；勾选后同时发邮件。
- 邮件发送成功与否都会记进邮件记录。

### 重置学生密码

- 设置 → 重置学生密码：选择学生，生成临时密码。
- **临时密码只显示一次**，请当场抄给学生；学生登录后应立刻改成自己的密码。

## 5. 课堂：课件投屏、任务、提交情况、互评

「课堂」对应第 1 章课件与课堂任务。

| 功能 | 说明 |
|---|---|
| **课件投屏** | 逐页翻，点「投屏模式」可以把当前页放大给教室看 |
| **课堂任务** | 第 1 章有 5 个任务：课前小调查（投票）、证据等级判别（测验）、倒推我的时间轴（表单）、AI 幻觉侦探（表单）、我的 AI 使用承诺（表单） |
| **提交情况** | 看谁交了、谁没交；**测验答案与解析不下发到学生浏览器**，由服务端判分 |
| **开启互评** | 给填写类任务开启互评：每份作业分给 2 位同学，**不会分给作者本人**，按负担最轻优先分配。再点一次只给新提交的补分配 |
| **解锁这一章** | 控制学生能否进入该章内容 |

**互评的隐私设计**：学生端显示为"同学作业 A/B"，**看不到作者**；被评者只看到平均分和建议，**看不到评价者**。你作为教师能看到完成率，也能在评分页看到互评结果。

## 6. 评分：档案袋打分与成绩表导出

「评分」是结课阶段的主战场。

### 全班一张表

显示每个学生的：各单项分数或档案状态、总评、是否已提交。

### 单个学生

点进去可以看到：档案指标、**缺项提示**、量规、已提交的行动方案与反思、AI 使用说明。然后**逐项打分并写评语（0—100）**。

五项权重（写在 `shared/assessment.json`，与申报表一致）：

| 项目 | 权重 |
|---|---|
| 院校分析表 | 15% |
| 计划与复盘 | 15% |
| 知识库 | 20% |
| 课堂与互评 | 10% |
| 终结性（行动方案 + 反思 + AI 使用说明） | 40% |

几条规矩：

- **平台指标仅供参考，最终分数由你决定。** 平台给的是过程数据（核验比例、打卡天数、反思字数……），不是分数。
- **五项都评完才算总评**；没评完的学生在成绩表里会注明"未评：……"，不会算出一个假的平均分。
- **学生只能看到自己的分数**，看不到别人的。

### 导出成绩表

点导出，得到 **CSV（UTF-8 带 BOM，Excel 直接打开不乱码）**，列为：

> 学号、姓名、五项（带权重）、总评（加权）、备注

结构与申报表考核结构一致。

## 7. 导师工坊：把导师调成你想要的样子

「导师工坊」是平台的核心可配置部分。**建议先花时间看一遍，再决定改哪里。**

### 角色卡与版本

每位导师有一张**角色卡**：语气、表达要求、职责边界、负面清单、示例对话。

| 概念 | 说明 |
|---|---|
| **草稿 vs 发布版** | 编辑只改**草稿**；**学生端始终读"当前发布版本"**，所以你改到一半不会影响学生 |
| **发布** | 发布生成新版本（v1.1、v1.2……），记录修改人、修改说明、测试结果 |
| **回滚** | 可以回滚到任一历史版本。**回滚到旧版本后，旧版本没有的资料也不再被检索** |
| **不丢记忆** | 切换版本**不清空学生的记忆** |

### 知识库（给导师的资料）

- 上传 PDF / Word / TXT / Markdown，或贴单页网页链接、粘贴文字。
- **必须写来源与授权说明**，并勾选"非未公开试题、非受版权保护的完整书籍、不含学生个人信息"——**这是硬性要求，缺一项不能入库**。
- **含身份证号、手机号、住址、家庭经济、健康信息的材料会直接拒收**。
- 资料约 500 字切片写入检索索引，导师回答前检索最相关的 3 片，**至少命中 2 个三字片段才引用**，避免硬塞。
- **新资料先进草稿，发布后才被检索**；**禁用立即生效**。

### 引用与来源

- 导师回答引用资料时句末标 `[资料1]`，消息下方显示来源标签（资料名 + 证据等级），点开可看片段。
- **只显示回答里真正引用到的来源**。
- 学生端的导师卡会显示"AI导师 · 版本 v1.3 · 依据 12 份资料 · 本周根据同学们的反馈更新了 2 处"。

### 测试集与回归

- 每位导师配 10—30 个测试问题与应答要点。
- 点「一键运行」：**发布版和草稿分别回答同一批问题，逐题并排对照，统计要点覆盖率**。
- **是否发布由你判断**——平台只给数据，不给"通过/不通过"。

### 反馈蒸馏

- 学生给导师回复打「有帮助 / 没帮助 + 原因」。
- 你在这里**只看到评分、原因标签和被评价的那一条回复**——**看不到学生发的话，也看不到是谁评的**。
- 点「生成改进建议」会输出：反复出现的问题、证据条数、具体修改建议（角色卡措辞 / 示例对话 / 负面清单 / 补充资料）、理由与副作用。**逐条采纳（写进草稿）或拒绝**，采纳后要发布才生效。

### 经验库与经验案例

- 经验库由平台从**至少 3 名同学**共有的匿名数据规则汇总（周复盘卡点、院校核验比例、高频干预、阅读卡"我的判断"空缺），**不调用模型、不含个人信息**。
- **必须教师批准才进入对应导师的上下文**；含学生姓名、学号、手机号的条目**不能批准**。
- 渡舟的经验案例还要勾选"已匿名"、写本人同意说明并通过个人信息检查。

## 8. 成效：给赛事和教学改进用的证据

「成效」看板是**给赛事材料用的**，所以它的设计原则是：**每个数字都能追溯到原始记录**。

### 只统计真实班级

**评委演示账号和沙箱班级的数据全部排除**，不进任何指标。你可以放心让评委随便试。

### 指标分组

| 分组 | 包含 |
|---|---|
| 规模 | 注册、活跃等 |
| 流程漏斗 | 各站完成人数 |
| 执行 | 今日打卡率、7 日完成率、14 天趋势、连续打卡分布 |
| 干预 | 各规则触发次数、响应率、**响应前后 7 天完成率变化** |
| 学习产物 | 知识库、阅读卡、选题卡等 |
| 课堂 | 任务提交、测验、互评 |
| 前中后测与满意度 | 含推荐度 NPS |
| AI 使用 | 调用次数、用途分布、**修改率**、核验次数 |

### 每个数字都能下钻

**点开任何数字，会显示构成这个数的原始记录列表。** 这是核查证据时最有用的功能——被问"这个 87% 怎么来的"，直接点开给对方看。

### 导出

- **Excel（.xlsx，8 个工作表）**：含**口径说明**与下钻接口，不引第三方依赖。
- **图表可下载 PNG**，也可以切换成**表格视图**。

> **注意**：图表用的是品牌绿同一色相由浅到深的顺序色，并跑了色盲可辨性校验；最浅一档对比度不足，所以每根柱子都带数值标签并提供表格视图。引用时请连表格一起给。

## 9. 设置：模型、Key、机构、评委账号

「设置」是运维中心，分区如下。

### 模型与 Key

| 项 | 说明 |
|---|---|
| 接口地址 | 中转站地址（例如 `https://token.agentone.work/v1`） |
| 平台 Key | **加密保存，只显示末 4 位**，永远不下发到浏览器 |
| 对话模型 / 推理模型 | 填模型名。**若模型是推理模型，建议保持关闭思考**，否则会先输出一段隐藏思考、把 token 用完，正文反而变空 |
| 检索服务 | `bocha` / `relay` / `none`。填了 Key 才能联网 |
| 「测试连通」 | 拉模型列表 + 试一轮流式对话，确认配置可用 |
| 本月用量 / 月度预算 | 超过预算会自动暂停并给中文提示 |

### 邮件

- `SMTP_USER` 填发信邮箱，`SMTP_PASS` 填 **SMTP 授权码**（QQ 邮箱在「设置 → 账户」里开启 SMTP 服务后生成，**不是邮箱登录密码**）。
- 点「发送测试邮件」立刻验证。
- **未配置或发送失败不影响任何其它功能**：干预照常写入、站内提醒照常显示、邮件记录留一条失败原因。

### 邀请码 / 模块分级 / 已核实资料 / 用量

见 [第 2 节](#2-开课前必须配置的几件事)。

### 机构信息与匿名演示模式

- **机构信息**：学校、学院、教师姓名——用于打印抬头，以及匿名模式下的替换词。
- **匿名演示模式**：开启后，**所有接口返回、SSE 流式对话、打印版与 CSV、Excel / Word 导出、邮件**里的学校名、学院名、教师姓名、额外关键词、**所有学生姓名与长学号**都会替换为"某地方本科院校""某学院""教师A""学生001"。
  - 英文登录名（如 `teacher`）**不替换**，避免破坏接口路径。
  - 演示前后的看板数字会不同，**截图做材料时请注意当前状态**。

### 评委测试账号

- 一键生成（1—10 个，有效期 1—60 天，可写备注）。
- 放在**评委沙箱班级**，标记为"演示"，学生的页面顶部会有演示提示。
- **过期后登录被拒、已有会话失效**。
- **沙箱邀请码不能自助注册**——评委账号只能由你生成。
- 有**单独的每日调用上限**（默认 40 次）；演示账号的调用同样计数。
- 可以删除账号及其全部演示数据。

### 检索测试 / 已核实资料

- 检索测试：填个查询词，直接看检索服务返回什么——**排查"检索到底通没通"最快的办法**。
- 已核实资料：官方文件里的事实，写在这里，检索不可用时也能用。

### 运行日志

「成效」里能看到每天的请求总数、正常拒绝（4xx）、服务器错误、成功率——这是"技术实现"维度的证据。

## 10. 隐私边界：教师能看到什么、看不到什么

**这是平台设计上最硬的一条线，请务必理解，也请这样跟学生讲。**

| 内容 | 教师能否看到 |
|---|---|
| 学生与导师的 **1:1 私聊原文** | ❌ 看不到 |
| **会议发言原文** | ❌ 看不到 |
| **长期记忆内容** | ❌ 看不到（只显示条数） |
| **数字分身**及其档案 | ❌ 看不到 |
| **学生上传的文件内容** | ❌ 看不到 |
| 学生给导师的**反馈内容与身份** | ❌ 看不到（只看得到评分、原因标签和被评价的那条回复） |
| 主线进度、打卡、方案、院校表、成果 | ✅ 看得到 |
| 知识库概况、选题卡、课堂与互评 | ✅ 看得到 |
| 考核档案袋、行动方案与反思、AI 使用说明 | ✅ 看得到（这是要评分的） |
| 邮件记录 | ✅ 看得到 |

另外：

- **"我的判断""我的反思"这两栏只有学生自己能写。** 平台里没有任何代码路径会让模型或教师写入这两栏。
- 学生**可以导出**自己的全部数据，也**可以注销**（注销会清空其数据）。
- 教师访问学生的私聊、记忆、分身、会议接口会返回 **403**。

> **给学生的说明建议**：直接告诉学生"老师看不到你和导师的私聊、看不到你的分身在说什么"，他们才会说真话。**这个平台的画像与反思质量，取决于学生敢不敢写真的。**

## 11. 日常维护与常见问题

### 建议的日常动作

| 频率 | 做什么 |
|---|---|
| 每天 | 看「概览」的今日打卡率；看学生列表里的"待处理提醒"，对连续断卡的学生点进去看看 |
| 每周 | 看「学生」里的周复盘情况；在「导师工坊 → 反馈蒸馏」看有没有反复出现的负面评价，采纳改进建议后发布 |
| 结课前 | 检查档案袋完成度；开启互评；导出成绩表 |
| 展示前 | 确认**匿名演示模式的状态**；确认看板数字口径；导出 Excel 与图表 PNG |

### 常见问题

**Q：检索用不了，学生还能做择校吗？**
A：能。平台会明确提示检索不可用，并降级为"学生贴官网链接 + 手动核验"。**AI 不会编造分数线**——查不到就标"待核实"。你也可以先把关键事实写进「已核实资料」。

**Q：学生报告"AI 回复是空的"？**
A：多半是推理模型把 token 花在了隐藏思考上。到「设置 → 模型与 Key」确认**思考模式是关闭的**。

**Q：想改导师的说话方式，会影响已经在用的学生吗？**
A：不会。你改的是草稿，**发布后**才生效；而且**不会清空学生的记忆**。改完可以用「测试集」跑一遍对照，满意再发布。

**Q：评委用完了，怎么清理？**
A：设置 → 评委测试账号 → 删除账号及其演示数据。**演示数据本来就不进任何统计**，删掉只是清理页面。

**Q：成绩表打开乱码？**
A：导出的 CSV 带 UTF-8 BOM，Excel 直接双击就能正常显示。如果用的是 WPS 老版本，选"UTF-8"编码打开。

**Q：收到了 SMTP 的 535 Login fail？**
A：这通常是邮箱**没有开启 SMTP 服务**，或者用的是邮箱登录密码而不是**授权码**。去 QQ 邮箱「设置 → 账户 → POP3/SMTP服务」开启一次，重新生成授权码填进去。

**Q：能同时开多个老师的账号吗？**
A：可以，`.env` 的 `TEACHER_ACCOUNTS` 用逗号分隔多组 `用户名:密码`。

**Q：怎么知道平台现在是不是最新代码？**
A：重启服务后访问 `/api/health`，返回 `{"ok":true}` 即正常。改完代码请**重启服务**——运行中的进程不会自动加载新代码。
