## 1. 开始之前

开学第一次上课前，老师会给你两样东西：

| 需要的东西 | 从哪来 | 说明 |
|---|---|---|
| **班级邀请码** | 老师发的（例如 `SHANHAI2026`） | 注册时必填，填错注册不了 |
| **学号** | 你自己的学号 | 3—32 位，只能用字母、数字、下划线、短横线 |

另外准备一个**邮箱**（推荐 QQ 邮箱）。邮箱有两个用途：接收提醒邮件、以及以后找回密码时用。

> **关于要不要自己买 AI 的 Key**：**不需要**。平台自带一个"基础模式"，不花钱、不用配置就能用：和搭子聊天、写画像、选方向、做方案、打卡复盘、周复盘会、复试模拟（基础版）都不需要你自己的 Key。
> 只有"高阶模块"（联网检索择校、学术进阶的四位科研导师、知识库问答、完整考官组复试、分身参加会议等）才需要绑定你自己的 Key——**不绑定也能用，只是少了联网和进阶能力**。详见 [第 10 节](#10-我key数字分身api-实验室)。

## 2. 注册与登录

### 注册

打开平台首页 → 点「注册」，填写：

| 字段 | 怎么填 |
|---|---|
| 班级邀请码 | 老师给的邀请码 |
| 学号 | 你的学号（**记住它，以后用它登录**） |
| 姓名 | 真实姓名 |
| 邮箱 | 推荐 QQ 邮箱，用于提醒 |
| 专业 | 例如"汉语言文学" |
| 年级 | 下拉选择：大一 / 大二 / 大三 / 大四 / 其他 |
| 专业大类 | 下拉选择（文史 / 理工 / 经管 / 艺体等） |
| 密码 | **至少 8 位** |
| 再输一次密码 | 两次要一致 |

几点提醒：

- **学号填了之后不能改**，而且不能和别人重复——如果提示"这个学号已经注册过了"，说明你以前注册过，直接去登录。
- 密码请自己记好。教师可以帮你重置，但重置后你必须立刻改成一个自己记得住的。
- 如果提示"邀请码不正确"，先检查有没有多打了空格，再找老师确认。

### 登录

首页 → 输入**学号**和密码 → 登录。

- 连续登录失败会被短暂限制（防止别人猜密码），稍等一会儿再试。
- 忘记密码：找老师，老师可以在后台给你一个临时密码。
- 教师账号（用户名是 `teacher` 这类）在同一个登录框登录，但**注册页注册不出教师账号**。

## 3. 出发准备（第1站）

**注册之后的第一次登录，你会被自动带到 `/prepare` 页面。** 这是第 1 站，一共四步，走完才能进主线：

| 步骤 | 你要做的事 |
|---|---|
| 第一步 · AI 使用须知 | 读完使用须知，勾选"我已阅读并同意"。这里会告诉你 AI 能帮你做什么、不能帮你做什么、以及学术诚信的底线 |
| 第二步 · 模块分级 | 了解"基础 / 高阶"的区别：哪些不用自己的 Key、哪些需要 |
| 第三步 · 前测问卷 | 认真填完。**这份问卷和你结课时的后测是同一组题**，是衡量你成长的依据，不认真填就测不出变化 |
| 第四步 · 选陪伴导师 | 从四位里选一位：栖云（温和陪伴）、砺行（严格督学）、观澜（策略规划）、知趣（轻松同行）。**选谁都行，随时可以换** |

四步都完成后，第 1 站亮起，进入主线。

## 4. 界面总览

### 导航

- **电脑**：左侧竖排导航，可点左上角的菜单按钮展开/收起。
- **手机**：底部横排导航。

学生端有 **6 个一级入口**：

| 入口 | 里面有什么 |
|---|---|
| **今日** | 今天的任务、打卡入口、待处理提醒、导师团通知、首页山水长卷 |
| **我的路** | 11 站主线地图 + 各站工作页 |
| **导师团** | 1:1 搭子对话、多位导师同场会议、"问一位导师" |
| **书房** | 知识库（两个空间）、学术进阶、成果登记 |
| **成长档案** | 考核档案袋、行动方案、AI 使用说明、互评、问卷 |
| **我** | 基本信息、API Key 设置、数字分身、API 实验室、注销 |

### 首页的山水长卷

- 首页是一幅**三维水墨山水**，11 个站点沿山路排布，**当前站会有高亮光环**。
- 点「看看这一站：×××」，镜头会推近到当前站，并弹出这一站的说明。
- 点「看完整11站」能看到全部站点清单。
- **卡顿或者不喜欢动效？** 点页面上的「简洁模式」，会切换成静态的平面山水，功能完全一样。这个选择只存在你自己的浏览器里。
- 如果设备不支持 3D，平台会**自动**换成平面山水并给出提示，不需要你做任何事。

### 用键盘 / 读屏

- 页面最上方有一个「跳到正文」的链接，按 Tab 第一个就能看到。
- 弹出面板时，键盘焦点会锁在面板里，按 `Esc` 关闭后焦点回到你刚才点的按钮。
- 系统设置里开启"减少动画"后，平台会自动关掉视差和雾层动效。

## 5. 11 站主线：每一站做什么

打开「我的路」可以看到全部 11 站。**站与站之间有先后顺序**——上一站没完成，下一站的工作页会用不了，这是故意的，因为后面的站要用到前面的产物（比如没做画像就选不了方向）。

| 站 | 名称 | 你要做什么 | 怎么算完成 |
|---|---|---|---|
| 1 | **出发准备** | 读须知并同意、了解模块分级、填前测问卷、选陪伴导师 | 四步全部完成 |
| 2 | **认识自己** | 和访谈导师**启微**用"菜单题 + 追问"聊一轮，生成你的画像，**逐条确认或修改** | 你点过"确认" |
| 3 | **选择方向** | 和方向导师**望岳**比较几条路（考研 / 就业 / 考公选调 / 保研…）的利弊与代价，**自己选定一条，并写下不少于 30 字的理由** | 理由写够字数并提交 |
| 4 | **选定目标** | 在择校工作台按条件筛出"冲刺 / 稳妥 / 保底"三层候选，**逐条核验**（平台会去查官方来源），写下**选择依据**和**不确定之处** | 依据与不确定之处都写完 |
| 5 | **制定方案** | 和计划导师**知序**生成一份贴合你每周可支配时间的阶段计划，**改到能用**，再点「采用这份方案」 | 点过"采用" |
| 6 | **坚持执行** | 每天勾任务 + 写一句真实复盘；每周做一次周复盘会 | 打卡与周复盘持续进行 |
| 7 | **建知识库** | 整理知识清单、错题、学习笔记，建立你自己的备考空间 | 有实际录入的条目 |
| 8 | **学术进阶** | 从检索式开始，读真文献、做阅读卡，最后收敛出一个**可做的问题** | 有阅读卡 + 选题卡 |
| 9 | **成果铺垫** | 登记你想参加的竞赛 / 大创 / 证书，跟着阶段推进 | 登记并推进 |
| 10 | **复试准备** | 练一次模拟问答（基础版免费），把答不好的问题留下来重练 | 完成一次模拟 + 复盘 |
| 11 | **结课** | 汇编行动方案、写反思与 AI 使用说明、参加展示与互评、完成后测 | 提交档案袋 |

> **中途可以重来吗？** 可以。画像、方案、择校表都能改；第 3 站的路径可以重选；方案可以重新生成。只有**已提交的结课档案袋**不能再改——这是考核要求。

### 第 2 站：认识自己（画像）

- 平台会问你一批**选择题（菜单题）**，你选完它会追问。**追问是重点**，比如它会问"当老师的念头是你自己的，还是因为你熟悉这条路？"
- 生成画像后，**每一条你都可以改**。改成你自己的话，比 AI 写的更准。
- **AI 写的原稿会被记下来**，你在结课时会看到自己"改了多少、直接用了多少"，这是 AI 使用说明的一部分。所以放心改，改了才有记录。

### 第 4 站：选定目标（择校）

- 平台会按你的条件给出候选院校。**如果联网检索不可用，平台会明确告诉你，并降级成"你自己贴官网链接、手动核验"** —— 它**不会编造分数线、报录比、招生人数**。所有未经核实的数字一律标为"待核实 / AI推断"。
- **核验状态是常态可见的**（一开始全都显示"⚠️ 待核验"）。看到"已核验"才说明平台真的去官方来源查过。

### 第 5 站：制定方案

- 方案会按你填的"每周可支配时间"来生成，**不会超上限**。
- 生成后请**改到能用**再"采用"——比如把某天改成你确实有空的时段。
- 采用之后，方案里的任务会出现在「今日」，打卡就是对它们打卡。

## 6. 每天要做的事：打卡与复盘

**这是平台里最重要的日常动作。**

### 每日打卡

打开「今日」→ 完成当天任务 → 点打卡 → 系统给你的印章是动效的。

- **打卡必须写一句复盘**，而且：
  - 不能太短（太短会被拦下）；
  - **不能和前一天写成一样**（照抄会被识别）。
- 写一句**真实的**就够了，比如"今天英语阅读错 3 个，都是长难句；明天先攻这个"。这比写"今天很充实"有用得多。
- 一天可以改一次，但不会重复计数。

### 每周周复盘

- 每周到「导师团」开一次**周复盘会**，会有一位主持（司南）和几位导师在场。
- 结束后会生成**纪要**，包括"共识 / 分歧 / 决定"和几条**行动项**。
- **行动项要你自己勾选确认才会写进你的方案**——平台不会背着你改你的计划。
- 纪要默认是**草稿**状态，你可以先看、再确认。

### 平台的"主动提醒"

平台会用规则（不是 AI 猜的）判断你需不需要帮忙，比如：

- 今天有任务但到点还没打卡 → 提醒你（只发邮件，不打扰你页面）；
- **连续两天没打卡** → 会问你是"任务太重"还是"这几天有事"，并给你处理选项；
- 最近 7 天打卡不少但完成率很低 → 说明计划过载，可以选"减量"、"延后"、"找人帮忙"等；
- 同一类提醒 **3 天内不会重复**，不会烦你。

提醒会以**卡片**形式出现在「今日」顶部。**请选一项回应**——选了平台才会据此调整，不选就一直挂着。

## 7. 导师团：一对一搭子与多位导师同场

### 1:1 搭子对话

- 每位导师有自己的**名字与职责**（例如"栖云｜温和陪伴"），页面上会一起显示。
- 对话是**流式**的（字是一个一个出来的），每轮结束会给几个**选项**，你可以点选项，也可以自己打字。
- **搭子有长期记忆**：它记得你说过的目标、状态、困难。你可以随时打开「它记得什么」看到它记了什么、**并且可以删**。

### 多位导师同场（会议）

在「导师团」里可以发起 6 种会议：

| 会议 | 什么时候用 |
|---|---|
| 周复盘会 | 每周一次，回顾这周做了什么、下周怎么调 |
| 方向研讨会 | 在几条路之间摇摆时，让导师们各自摊开代价 |
| 择校评审会 | 候选院校定不下来时 |
| 卡住了求助 | 具体某件事过不去时 |
| 科研组会 | 文献和选题阶段 |
| 自由讨论 | 你自己想聊的主题 |

- 会议是**多位导师依次发言**，每人说的内容不一样，而且**后一位会回应前一位**。
- 你可以 `@某位导师` 让他发言，也可以**静音**某人（静音后连 `@` 都不发言，邀请一次就解除）。
- 结束后生成纪要，**勾选才写进方案**（见上一节）。

### 问一位导师

「导师团 → 问一位导师」可以指名问某一位（明章 / 渡舟 / 习法 / 望岳 / 择川 / 知序等）。
**回答里引用资料时，句末会标 `[资料1]`，下方有来源标签，点开能看片段**——这是为了让你能核对，而不是盲信。

### 给导师反馈

每条导师回复下面有「有帮助 / 没帮助 + 原因」的按钮（原因包括：太严厉、太啰嗦、不准确、没听懂我、太空泛、其他）。

- 你的反馈**匿名**：老师只能看到"这条回复被打了什么分、什么原因标签"，**看不到你说了什么、也看不到是谁评的**。
- 平台会拿这些反馈去改进导师（比如把"太严厉"的措辞改掉）——**改进的是导师的说话方式，不是训练大模型**。

## 8. 书房：知识库、学术进阶、成果

「书房」有三个工作台。

### 知识库

- 你可以**手动录入**，也可以**导入**（支持 RIS / EndNote / NoteExpress / RefWorks / CSV / DOI 列表 / BibTeX），还能上传 PDF / Word / TXT / Markdown 或贴网页链接。
- 中文 GBK 编码的文件也能自动识别，不会乱码。
- 重复导入会被识别为"重复"，不会重复入库。
- **导出**：BibTeX、RIS、CSV、JSON 备份、Markdown（阅读卡打包成 ZIP）。

### 学术进阶

四位科研导师分工：

| 导师 | 职责 |
|---|---|
| 寻源 | 检索（帮你把模糊的兴趣变成能检索的检索式） |
| 照卷 | 阅读（陪你精读一篇真文献） |
| 织理 | 分类（把文献整理成主题与子主题） |
| 问枢 | 选题（把阅读收敛成一个可做的问题） |

- 读文献时要做**阅读卡**，里面有「**我的判断**」这一栏——**这一栏永远只有你能写**，平台不会代写，默认是空的、等你填。
- **边界提醒**：平台**不会**帮你写综述、代写、润色成稿、翻译成稿、投稿排版。这些请求会被礼貌拒绝。它能帮你**精读、讨论方法、整理思路**。

### 成果

- 有 8 类成果目录（竞赛、大创、证书、实习、科研等），带时间规律和注意事项。
- **临近截止的会标成"紧急"**，帮你把注意力放到该放的地方。
- 登记录入后按"了解中 → 组队/找导师 → 选题 → 推进中 → 提交 → 已完成"推进。

## 9. 成长档案与结课

「成长档案」（手机上也叫第 11 站）是**考核档案袋**，五项按申报表权重：

| 项目 | 权重 |
|---|---|
| 院校分析表 | 15% |
| 计划与复盘 | 15% |
| 知识库 | 20% |
| 课堂与互评 | 10% |
| 终结性（行动方案 + 反思 + AI 使用说明） | 40% |

- 顶部**一眼就能看出缺哪几项**，每项都有"已完成 / 进行中 / 未开始"和**平台指标**（核验比例、打卡天数、周复盘次数、阅读卡数……）。
- 补缺之后依次做：

| 步骤 | 说明 |
|---|---|
| **汇编行动方案** | 一键把画像、路径、择校表、方案与复盘、知识库、成果、复试准备汇编成 7 个部分。**这是模板拼装，不调用 AI** |
| **写"我的反思"** | 每个部分要写一条（≥30 字）。**这一栏只能由你写**——平台里没有任何代码路径会往这里写内容，而且把汇编内容原样抄过来会被拦下 |
| **写 AI 使用说明** | 平台会列出你**真实的调用统计**（各用途调用次数、平台 Key / 自己的 Key、token、时间），以及核验情况、以及你对 AI 产物的处理（直接采用 / 修改 / 否决 + **修改率**）。你在此基础上写一段补充说明（≥50 字） |
| **提交** | 提交时统计数字**定格**，之后不能再改 |
| **参加互评与展示** | 老师会开启互评：每份作业分给 2 位同学。**你看不到作者是谁**（显示为"同学作业 A/B"），被评者也看不到评价者。按量规点"信息可靠 / 逻辑清楚 / 可执行"并写一句建议 |
| **问卷** | 填中测、后测和满意度问卷，还能看到"我和起点相比"的逐题变化（**只有你自己能看到**） |

> **公平性**：档案袋的完成状态**只依据不需要自带 Key 的功能**。也就是说，你全程不绑自己的 Key，也能把五项全部做完。

## 10. 「我」：Key、数字分身、API 实验室

### 基本信息与设置

在「我」里可以改姓名、邮箱、提醒时间、邮件提醒开关。

### 我的 API Key（`我 → 设置`）

| 部分 | 说明 |
|---|---|
| 模块权限 | 显示每个模块是"基础"还是"高阶"，哪些需要你的 Key |
| 我的 API Key | **粘贴你自己的 Key**。可以"测试连通"再保存。**Key 只存在你自己的浏览器里**，不会存到服务器 |
| 我的模型 | 可以指定用哪个模型 |
| 偏好 | 例如"基础模块也用我的 Key" |
| 我的用量 | 看看平台 Key 和你的 Key 各用了多少 |
| 删除 | 随时删掉你的 Key |

**两级 Key 是怎么分工的：**

- **平台 Key**（老师配置的）：负责基础模块。**它永远不下发到你的浏览器**，是服务器直接调的。你每天有基础额度（默认 60 次），用量在页面上可见。
- **你的 Key**：负责高阶模块。它**只在你的浏览器里**，需要时通过请求头 `X-User-Key` 发到服务器，**服务器不保存、日志里也只会显示成 `sk-****`**。关掉浏览器它也还在你的浏览器里，别的同学看不到。

### 数字分身（`我 → 数字分身`）

- **必须你本人同意**才能建立。
- 分身的数据来源你可以**逐项开关**（比如关掉"打卡与复盘"，分身里就不会有打卡内容）。
- 你可以**上传自己的资料**：含手机号、身份证号等内容会在入库前**自动遮盖**（会告诉你遮了几处）。
- 生成后**每条你都能校正、能锁定**（锁定后重新生成不会覆盖你的改动）。
- 分身能**参加周复盘会**发言、能做**复试彩排**（先由分身作答、你再看差距）、能和"**未来的我**"对话。分身说的话都会标「**分身推测**」，**不会冒充你真的做过什么**。
- **老师看不到分身**，也看不到你上传的资料内容。
- **随时可以删**：点删除会连档案、校正记录、对话、会议里的分身发言一起清掉。

### API 实验室（`我 → API 实验室`）

课堂任务会用到。可以拉模型列表、试对话、保存"我的小智能体"。**需要你自己的 Key**；临时试用的 Key 不会被保存。

### 注销账号（`我 → 注销账号`）

需要输入正确的密码和确认词。**注销会清空你在平台上的全部数据**（消息、记忆、分身、档案……），清理得比较彻底，请谨慎。

## 11. 你的数据由你掌控

平台在数据上守几条规矩，你可以放心：

| 规矩 | 具体表现 |
|---|---|
| **教师看不到你的私密内容** | 老师**看不到**你和导师的 1:1 私聊原文、看不到会议发言原文、看不到你的长期记忆内容（只能看到条数）、看不到数字分身和你上传的文件 |
| **反馈匿名** | 老师看不到你给导师的反馈内容，也看不到是谁评的 |
| **"我的判断""我的反思"只有你能写** | 平台里没有任何代码路径会代写这两栏 |
| **随时导出** | 「我」里可以导出你的全部数据 |
| **随时清除** | 可以删记忆、删分身、注销账号 |
| **演示数据不混入统计** | 演示账号（评委用）的数据都标着"演示"，**不计入任何统计** |

## 12. 常见问题

**Q：一定要自己买 AI 的 Key 吗？**
A：不一定。基础模块不用；只有高阶模块（联网择校、科研四导师、知识库问答、完整考官组、分身参会等）需要。而且档案袋的完成状态不依赖自带 Key。

**Q：AI 会不会替我把作业写完？**
A：不会，也不该。平台会拦下"帮我写综述 / 代写 / 润色成稿 / 翻译成稿 / 投稿排版"这类请求。它的定位是陪你**把想清楚的事说清楚、把文献读懂、把方案改到能用**。

**Q：我的 Key 会泄露吗？**
A：平台不会把它存到服务器，日志里也只显示 `sk-****`。但请注意：**Key 存在你自己的浏览器里**，所以别把电脑借给别人时开着登录状态。

**Q：平台会编造分数线吗？**
A：不会。查不到就标"待核实 / AI推断"，并明确告诉你检索不可用。**看到未经核实的数字，请当成待核验。**

**Q：打卡写不出东西怎么办？**
A：写一句**真实的**就行，哪怕只有一句"今天状态不好，只做了 20 分钟"。平台要的是真实记录，不是漂亮话。

**Q：忘了打卡怎么办？**
A：补不了，但平台会提醒你，而且**连续两天没打卡会自动问你原因**，据此调整——它不会用扣分逼你。

**Q：为什么下一站点不进去？**
A：站与站有先后依赖（比如没做画像就选不了方向）。回到上一站完成它。

**Q：手机上能用吗？**
A：能。底部导航是五格（今日 / 我的路 / 导师团 / 书房 / 我），360—1920 宽的屏幕都不会错位。3D 后台会自动降级。

**Q：觉得卡顿怎么办？**
A：点首页的「简洁模式」，或在系统设置里开启"减少动画"。

**Q：想把记录带走？**
A：可以。「我」里导出全部数据；结课的档案袋还能导出 **Word** 和**打印版**；教师的成绩表是 **CSV**。
